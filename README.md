# GGD Identity Overlay v7 Complete

目标：`com.seayoo.ggd` / `1.1.13` / arm64 / iOS 18+

这一版把前面已经确定的功能一次合并到一个 `GGDFinal.mm`：

- 独立悬浮 `UIWindow`，不再挂到游戏原窗口上
- GGD 小球支持手指拖动，并保存位置
- 点击小球打开/收起玩家面板
- 面板固定有“立即读取玩家”手动按钮
- 可打开“自动刷新（2秒）”
- 玩家按行显示：颜色球 / 阵营 / 身份 / 名称 / ID / UID
- 鹅 / 鸭 / 中立使用不同颜色球
- 已整理目标版本中已确认的角色 ID 文本；未知 ID 会直接显示 `未知角色 (ID n)`
- 游戏操作区域触摸穿透，只有 GGD 小球和面板按钮区域拦截触摸
- IL2CPP 不在注入构造函数阶段访问；只有点击读取后才初始化运行时
- 读取在主线程执行，避免 Unity/IL2CPP 对象跨线程访问
- 玩家读取优先使用目标 1.1.13 中已确认的玩家/BaseData/players 布局，元数据路径作为备用

## GitHub Actions

把本目录三个文件放进仓库根目录，提交到 `main`。Actions 会生成：

`GGDIdentityOverlay-v7-complete-arm64`

其中的 `GGDIdentityOverlay.dylib` 就是注入文件。

## 注入

继续使用你现在的签名/注入流程，目标仍然是游戏主可执行文件。第三方动态库保持注入到主程序的方式，路径使用：

`@executable`

目录：

`/`

## 使用

进入游戏后先看到 GGD 小球。小球可以直接拖动；点一下打开面板；点击“立即读取玩家”读取当前玩家信息；需要持续刷新时再打开“自动刷新（2秒）”。
